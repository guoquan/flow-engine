# Flow (服喽) 🌊

> **"一开口，就服喽。"** (Once it speaks, you're convinced.)

Flow 是一个高性能、轻量级的 Web 端数字人引擎。它旨在通过简单的 API 驱动，为 Web 应用赋予栩栩如生的 AI 化身（Digital Human）交互能力。

## 🌟 项目亮点

- **高性能渲染**：基于 WebGL/Three.js，确保在浏览器中流畅运行。
- **AI 驱动**：原生支持通过 API 驱动口型同步、表情变换和动作序列。
- **极简集成**：为前端开发者提供开箱即用的 SDK。
- **梗感命名**：中文名“服喽”，寓意技术折服人心，音译自英文名 Flow。

## 🛠 技术栈

- **Core**: Vanilla TypeScript
- **Rendering**: Three.js / WebGL
- **Build Tool**: Vite
- **Package Manager**: pnpm

## 📁 目录结构

- `src/`: 引擎核心源代码。
- `public/`: 静态资源，如模型 (GLB/VRM) 和纹理。
- `demo/`: 示例用例。

## 🚀 快速开始

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm run dev

# 构建生产版本
pnpm run build
```
